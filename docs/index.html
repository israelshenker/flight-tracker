Connect this browser to make changes

Anyone with the link can view this page. To add or stop flights, this browser needs a GitHub access key. You do this once per browser (computer or phone), and the key is kept only in that browser.

  1. Open GitHub's new access key page, signed in as israelshenker.
  2. Under Repository access, choose Only select repositories and pick flight-tracker.
  3. Under Permissions, make sure Contents and Actions are both Read and write.
  4. Click Generate token, copy it, and paste it below.

Trips

A trip groups route/dates, for you to filter by and, if you share it, for a read-only page you can send to friends or family. Its link opens only that trip: no other trips, no settings, no changes. Add routes to a trip from + Add flights or Select routes.

Settings

You get an email and push when a fare moves by either amount, up or down. 0 turns that one off. $1 means any change.

A skiplagged fare is a ticket to a city past your destination that connects there, when it's cheaper to book it and get off at the connection. One-way, carry-on only; round trips and routes with checked bags are skipped. Airlines forbid it and may penalize repeat use.
